USN Journal · симуляция

USNFile NameReason

Синтаксис: name: — имя файла, reason: — тип операции, ! — исключение, ; — объединение условий (логическое И)
Возможности

Что умеет JournalTrace

Минимализм снаружи, мощность внутри.

📄

Парсинг USN Journal

Читает журнал изменений NTFS напрямую через Win32 API и показывает каждое событие файловой системы.

🎛️

Продвинутые фильтры

Комбинируйте условия: name:.pf;reason:delete. Исключайте шум вроде svchost одним символом.

🖱️

Графический интерфейс

Никакого запоминания флагов — все фильтры настраиваются в GUI, но синтаксис для тех, кто любит точность.

⚡

Скорость

Работа с журналом через нативные обёртки UsnJournal и OpenByFileId — без лишних прослоек.

🕵️

След действий

Восстановите хронологию: что создано, переименовано, удалено — даже если сам файл уже не существует.

🪶

Синтаксис

Фильтры, которые находят всё

Точные запросы вместо тысяч строк ручного просмотра. Нажмите «копировать» — вставьте в JournalTrace.

поиск исполняемых файлов
name:.exe
Все события, связанные с .exe — создать, изменить, удалить, переименовать.
удалённые prefetch-файлы
name:.pf;reason:delete
Классика форензики: кто и когда удалял файлы предзагрузки.
с исключением системного шума
name:.exe !name:svchost
Все .exe, кроме вечного svchost — чтобы он не забивал выдачу.
следы переименований
reason:rename !name:.tmp
Отслеживание переименований без временных файлов — часто так маскируют вредоносное ПО.
